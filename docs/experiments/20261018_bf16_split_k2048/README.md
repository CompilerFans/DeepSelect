# bf16 split 接纳 `topk=2048`（C600-U / DSA decode）

日期:2026-10-18。设备:MetaX C600-U(28 AP,family 1600)。树:P6 之后(`7428e57` 为基)。
脚本:`ab_two_arms.py`；原始输出:`ab_raw.txt`（两臂交替、各两轮）。

## 0. 背景

`chunked_bf16_applies` 此前只接纳 `topk ∈ {512, 1024}`——两个 static-k 合并臂。
`topk=2048` 是 DSA decode 的生产形状之一，一直走路路径；在 b1..b6 × V≥256K 上
它正是**并行度受限**区(基线快照 `perf_data/MetaX_C600-U/20261018_152134`:
`b1-v262144-k2048` 121.3 µs / 4.4 GB/s)。而 split 的 runtime-k 臂
(`launch_bf16_chunk_stage{1,2}_*_runtime`,由 `bf16_stage1_topk_runtime_nan{0,1}` /
`bf16_stage2_topk_runtime` 承载)**早已编译、从未被路由**——本实验是它第一次被调用。

## 1. 测量

两臂 .so 交替放置、同会话、种子钉死(1234)、`kk.bench_by_cuda_events`(内核时间,
非 e2e)。合同检查(唯一索引 / 范围 / `value==input[idx]` / `min(sel)≥max(unsel)`)
在每一格每一臂均通过。

| cell | old(路路径) | new(split) | Δ |
|---|---|---|---|
| b1-v262144-k2048 | 174.0 / 168.6 µs | 126.0 / 120.4 µs | **−29%** |
| b6-v262144-k2048 | 192.7 / 195.5 | 145.5 / 148.5 | **−24%** |
| b1-v524288-k2048 | 243.3 / 241.3 | 126.2 / 121.7 | **−49%** |
| b1-v1048576-k2048 | 359.4 / 351.8 | 264.5¹ / 141.0 | **−26…−60%** |
| b1-v131072-k2048(V<门) | 132.1 / 138.4 | 132.8 / 139.0 | 0 |
| b1-v262144-k512 | 109.7 / 118.9 | 106.3 / 106.8 | 0 / 略好 |
| b6-v262144-k512 | 121.3 / 138.2 | 119.8 / 126.8 | 0 / 略好 |
| b1-v1048576-k512 | 120.6 / 132.8 | 114.0 / 120.4 | 0 / 略好 |

¹ new-r1 的 264.5 是第一轮单点离群(同臂第二轮 141.0,旧臂两轮稳定);结论按
new-r2 与旧臂中值取 −60%。

## 2. 落地

`routing.cuh` 的 `chunked_bf16_applies`:k2048 仅在 **128 KiB 部件**
(`is_c600u_ap_count`)上接纳,走 runtime-k 臂;C500(104 AP)保持行路径——
本机无 C500,未测量的路由变更不欠。**零新增实例化**(runtime 臂本就在产物里;
回执:三族各 89 文件不变)。
